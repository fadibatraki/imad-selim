# Imad Selim — Official Artist Website

A responsive artist portfolio website developed for **Imad Selim**, a singer based in Germany.

The website provides a central online presence for showcasing music releases, videos, artist information, and creative content.

**Live Website:** [imad-selim.vercel.app](https://imad-selim.vercel.app/)

## Project Overview

This project was developed and customized to create a dedicated digital presence for a professional music artist.

The website focuses on visual presentation, responsive layouts, and an accessible experience for visitors exploring the artist's work.

## Key Features

- Responsive website optimized for desktop and mobile devices.
- Artist portfolio and music presentation.
- Music videos and multimedia content.
- Dedicated sections for artist information and creative work.
- Reusable interface components and structured frontend code.

## Technology

- **Next.js** — React-based web framework.
- **React** — Component-based user interface.
- **Tailwind CSS** — Responsive styling and layout.
- **Vercel** — Website deployment and hosting.

## Development

My work on this project included:

- Customizing the website structure and visual presentation for the artist.
- Developing and adapting frontend components.
- Integrating music-related content and media.
- Preparing and deploying the production website.

## Local Development

Install dependencies:

```bash
npm install --legacy-peer-deps
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
